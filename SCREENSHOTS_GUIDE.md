# Guide des Captures d'Écran pour Soumission Pi Network

Ce document explique quelles captures d'écran prendre pour la soumission de votre application OrganicAgropastoralepi.pi à Pi Network App Store.

## Captures d'Écran Requises

Pi Network demande généralement **3 à 5 captures d'écran** représentatives de votre application.

### 1. Page d'Accueil / Landing Page
**Objectif:** Montrer la première impression de l'application

**Que capturer:**
- Titre "ORGANIC AGRO-PASTORAL PI"
- Description principale
- Liste des fonctionnalités
- Boutons d'action principaux
- Footer avec liens légaux

**Pourquoi:** C'est la vitrine de votre application

---

### 2. Marketplace / Produits Biologiques
**Objectif:** Démontrer la fonctionnalité principale de vente

**Que capturer:**
- Grille de produits avec images
- Prix en Pi
- Catégories de produits
- Boutons "Acheter"

**Pourquoi:** Montre l'utilité concrète de l'application

---

### 3. Système de Paiement Pi
**Objectif:** Prouver l'intégration Pi Network

**Que capturer:**
- Page de paiement avec montant en Pi
- Interface de confirmation de paiement
- Statut de transaction

**Pourquoi:** Validation technique de l'intégration Pi

---

### 4. Wallet / Tokens OAPPi
**Objectif:** Montrer la gestion financière

**Que capturer:**
- Solde Pi et tokens OAPPi
- Historique des transactions
- Statistiques utilisateur

**Pourquoi:** Démontre un écosystème complet

---

### 5. Contrats / Documents Légaux (Optionnel mais recommandé)
**Objectif:** Montrer la dimension professionnelle

**Que capturer:**
- Page des contrats
- Section actionnaires
- Documents légaux (statuts, règlement)

**Pourquoi:** Crédibilité et sérieux de l'entreprise

---

## Spécifications Techniques

### Format
- **Résolution recommandée:** 1080 x 1920 pixels (format mobile)
- **Format:** PNG ou JPG
- **Poids maximum:** 5 MB par image
- **Orientation:** Portrait (vertical)

### Qualité
- Image nette et claire
- Texte lisible
- Bon contraste
- Pas de contenu flou

### À éviter
- Captures d'écran avec informations personnelles réelles
- Images trop sombres ou surexposées
- Texte tronqué
- Erreurs visibles

---

## Comment Prendre les Captures

### Sur Mobile (recommandé pour format natif)
1. Ouvrez l'application sur votre téléphone
2. Naviguez vers la page à capturer
3. Appuyez sur Volume Bas + Bouton Power (Android)
4. Ou Bouton Power + Volume Haut (iPhone)

### Sur Ordinateur (pour preview v0)
1. Ouvrez l'application dans v0
2. Utilisez le mode responsive (F12 > Toggle Device Toolbar)
3. Réglez sur iPhone 12 Pro ou similar
4. Cliquez sur "Capture screenshot" ou utilisez un outil de capture

### Outils Recommandés
- **Snagit** (Windows/Mac)
- **Lightshot** (Windows/Mac)
- **Screenshot Tool** intégré au navigateur (Chrome DevTools)

---

## Checklist Avant Soumission

- [ ] 3 à 5 captures d'écran prêtes
- [ ] Toutes en format portrait
- [ ] Résolution correcte (1080 x 1920 ou similaire)
- [ ] Noms de fichiers clairs: `oappi-home.png`, `oappi-marketplace.png`, etc.
- [ ] Pas d'informations sensibles visibles
- [ ] Application en mode "production" (pas de textes de test)
- [ ] Toutes les images sous 5 MB

## Ordre de Présentation Recommandé

## Notes Importantes

- **Cohérence visuelle:** Toutes les captures doivent avoir le même thème/design
- **Langue:** Français (votre marché cible)
- **Données réalistes:** Utilisez des exemples crédibles, pas de "Lorem Ipsum"
- **Statut authentifié:** Montrez l'application connectée avec Pi Network
