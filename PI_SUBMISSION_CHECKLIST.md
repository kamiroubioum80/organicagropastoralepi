## 🚀 Étapes Complètes de Déploiement

### Étape 1: Déployer sur Vercel

1. Dans v0, cliquez sur "Publish" (ou téléchargez le code)
2. Connectez-vous à Vercel (vercel.com)
3. Importez votre projet
4. Déployez
5. Notez l'URL Vercel fournie (ex: `organicagropastoralepi.vercel.app`)

### Étape 2: Créer le Repository GitHub

1. GitHub.com → New repository
2. Nom: `organicagropastoralepi`
3. Public + README
4. Copiez l'URL

### Étape 3: Remplir Pi App Studio

1. Allez sur https://develop.pi
2. Sélectionnez votre app "OrganicAgropastoralepi.pi"
3. Remplissez tous les champs avec les URLs ci-dessus
4. Sauvegardez

### Étape 4: Soumettre pour Validation

1. Dans Pi App Studio, cliquez sur "Submit for Review"
2. Collez le texte de soumission (voir PI_NETWORK_SUBMISSION.md)
3. Attendez la validation (3-7 jours)
